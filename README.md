# Finances Telebot
Yearly, Monthly, Weekly, Daily Finances tracking for personal use

## Setup
1. create .env file and input your telebot api key
2. install dependencies, python-telegram-bot & python-dotenv

## Current Capabilites
### Commands
- /start
- /stats
- /add (not implemented yet)

#### Start
Allows users to create a transaction, customisable by: 
1. Expenditure or Income
2. Category (food, clothes, custom type)
3. Cost/Amount  
  
### Stats
Allows users to view expenditure and financial statistics:
1. Viewing of Balance
2. Monthly Statistics
3. Yearly Statistics
4. Breakdown based on categories (not implemented yet)
